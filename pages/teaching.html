CogSci 302: Introduction to Cognitive Modelling
New (2026) 300-level course for the Rutgers Center for Cognitive Science

An introduction to what a model of human cognition is, why to build one, and how to evaluate it, across topics in decision, memory, perception, and language. No programming background is required: students run and modify supplied model code in R.
